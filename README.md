# Web-Based Integrated Project-Monitoring Platform

## Overview

A web-based application designed to monitor infrastructure projects, track budgets and expenditure, analyse project progress, and identify potential financial and schedule risks.

## Problem Statement

Infrastructure projects may experience budget overruns, schedule delays, and difficulties in tracking actual expenditure and completed work. This platform aims to centralise project information and help stakeholders identify potential problems early.

## Objectives

- Monitor infrastructure project progress.
- Track approved budgets and actual expenditure.
- Compare planned progress with actual progress.
- Identify potential budget overruns and schedule delays.
- Generate risk alerts and monitoring reports.
- Support transparent and data-driven decision-making.

## Initial Features

1. Project Dashboard
2. Budget and Expenditure Tracking
3. Project Progress Monitoring
4. Budget Overrun Alerts
5. Schedule Delay Detection
6. Spending Anomaly Alerts
7. Project Risk Summary

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite
- Version Control: Git and GitHub

## Project Status

Initial setup and requirement planning.

## Data and Disclaimer

The initial prototype will use sample project data. Risk alerts are intended to support investigation and decision-making and do not independently establish fraud or regulatory violations.

## Future Enhancements

- Predictive project risk analysis
- Interactive charts and reports
- Role-based access for project stakeholders
